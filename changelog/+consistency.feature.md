Added the module `elicito.consistency`. It checks whether the expert information on the targets of a fitted eliobj is consistent. `detect(eliobj)` compares the loss of each target with the loss that sampling error alone gives. `slack(eliobj)` refits with a penalized shift per target, and shows which targets need a shift to fit and how large it is. `best_replication(eliobj)` finds the replication with the lowest loss; both checks start from it by default. All three support `method="parametric_prior"` only.
